# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SENTRA, please do NOT create a public GitHub issue. 

Instead, report it directly by emailing the maintainer or opening a Private Security Advisory on GitHub.

Please provide:
- Description of the vulnerability.
- Steps to reproduce or proof-of-concept payload.
- Potential impact and affected components.

We take security concerns seriously and will review and respond promptly.
